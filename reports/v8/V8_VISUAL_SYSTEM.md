# V8 Biological-Tech Visual System

V8 combines the approved unified discovery architecture with the Matrix visual DNA established in V6/V7. Decorative systems are abstract, carry no measurement or health meaning, and remain separate from canonical factual data.

| Component | Purpose | Intensity | Primary use | Motion and fallback | Accessibility / performance |
|---|---|---|---|---|---|
| `matrix-visual` | Shared atmospheric wrapper | High / medium | Homepage, Explore, Know Your Number, departments | Slow path drift and cell breathing; static under reduced motion | `aria-hidden`, pointer events disabled, CSS/SVG only |
| Biological field | Organic topology and depth | High | Major openings | Static gradient/radial field | No image request or content obstruction |
| Signal path | Connects product, context, evidence, decision | High / medium | Openings and transitions | Stroke-dash movement pauses offscreen and when hidden | Decorative SVG; no fake data |
| Node cluster | Biological signal landmarks | All | Search, departments, cards | Static glow with restrained parent motion | Never communicates factual status alone |
| Scan frame | Scientific interface boundary | Low | Search and product cards | Focus/hover response only | Strong visible focus and no pointer interception |
| Specimen stage | Keeps product imagery focal | High / low | Featured kit and product cards | Existing restrained product depth | Uses existing optimized canonical cutouts |
| Environment biome | Distinguishes six departments | High / medium | Department tiles and hubs | Shared static palette; optional parent signal motion | Text labels and counts remain primary identifiers |

| Evidence frame | Separates editorial results from products | Low | Search and Library | Hover/focus elevation only | Content types remain explicitly labeled |

## Intensity map

- Medium: department rail, Explore workspace, Product Universe, pathway transitions.
- Low: product cards, search results, Library cards, filters, disclosure and footer surfaces.

## Motion policy

New animation changes only transforms, opacity, and SVG dash offset. An `IntersectionObserver` pauses decorative motion offscreen; the visibility handler pauses it when the document is hidden. `prefers-reduced-motion: reduce` removes all new animation and hover translation while retaining a composed static state.

## Performance

No framework, runtime library, video, external search service, or new image payload was added. The visual layer is CSS/SVG. JavaScript grew 6.33%; active product imagery remains 1,103,598 bytes. Search-index growth supports typed result imagery and derived department metadata.
