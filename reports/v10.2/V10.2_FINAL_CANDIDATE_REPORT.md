## Scope delivered

V10.2 changes technical delivery and auditing only. Public copy, prices, products, destinations, navigation, claims, CSS, and JavaScript behavior are unchanged. Generated HTML changes are limited to deterministic CSS/JavaScript cache keys.

### Deterministic cache invalidation

Each generated CSS and JavaScript URL now receives the first 12 hexadecimal characters of that file's SHA-256 content digest. Text is normalized to Git's canonical LF representation before hashing, so Windows and Linux builds emit identical URLs. Identical content retains the same URL and a content change produces a new URL. The previous manually maintained `v11-candidate-1` label has been removed. Tests exercise stability, invalidation, cross-platform output, and generated-markup correctness.

### Published asset boundary

The previous 38,501,069-byte audit figure described repository assets, not an initial page transfer. After provenance path updates, the comparable combined repository set is 38,501,139 bytes. Twelve retained original-art files totaling 25,301,500 bytes now live under `_source-assets/`, which GitHub Pages' Jekyll boundary excludes from the published site. The public `assets/` directory is 13,199,639 bytes across 186 files; 164 referenced runtime assets total 11,890,408 bytes. No visible derivative was removed or recompressed.

The deterministic inventory reports 22 public orphan candidates for future review. They were not deleted because some are canonical source/provenance records or deferred-product assets. See `ASSET_INVENTORY.json`.

### Permanent daily audit

The daily workflow was absent from the production baseline, so V10.2 installs it. It runs at the two UTC times covering 08:00 CST/CDT and uses an `America/Chicago` guard to select the correct slot. Manual dispatch is supported. It explicitly checks out a fresh snapshot of `github.event.repository.default_branch` with persisted credentials disabled, records the audited SHA, and never switches, resets, or cleans a developer checkout.

The workflow performs the deterministic build, normal and strict-dry-run validation, all unit tests, asset inventory, compliance triage, live page/asset parity checks, and responsive Chromium auditing. Audit artifacts and a mandatory Next actions summary are retained for 30 days. Permissions are limited to `contents: read` and `actions: write`; it has no issue, deployment, package, secret, administration, or production-write permission.
